##############################1st phase##########################

https://samber.github.io/awesome-prometheus-alerts/ 
   This site best for alerts for prometheus !!!

first we create the file in /etc/prometheus 
alert.yml file we create and define the group and alert rules 

ex: 
groups:
  - name: <string>                              # Unique name for the group of rules
    [ interval: <duration> ]                    # Optional: How often to evaluate the rules
    rules:
      - alert: HostHighCPULoad
        expr: 1 - (avg without (cpu) (rate(node_cpu_seconds_total{mode="idle"}[5m]))) > .80
        for: 10m
        labels:
           severity: warning
        annotations:
            summary: Host high CPU load (instance {{ $labels.instance }})
            description: "CPU load is > 80%\n  VALUE = {{ $value }}\n  LABELS = {{ $labels }}"

we can define multiple name for diffrent grps and multiple alerts in one group!!


###############################2nd phase####################################

go in /etc/prometheus/prometheus.yml file

configure the file name in this file :

ex:
rule_files:
  - "alert.yml"

path of the alert rules file name !


##############################3rd phase#####################################

https://developer.couchbase.com/tutorial-configure-alertmanager/

Download  ALERTMANAGER and configure, run as a service using the upper link

use the script for this : alertmanager-installation.sh 

after installation we configure the alertmanager service ip:port in /etc/prometheus/prometheus.yml 

ex: 
alerting:
  alertmanagers:
    - static_configs:
        - targets:
            - 'localhost:9093'  <------------alertmanager ip and port


##############################4th phase#######################################

go in /etc/alertmanager/alertmanager.yml

exmple: put this in alertmanager.yml file
route:
  group_by: ['Alert']   #<--------group-name 
  receiver: 'email'     #<--------receiver-name
